Telegram Bot API docs for Vercel.

A hosted API wrapper, webhook receiver, and local real-time runner with safe Telegram flood handling built into the request path.

01

Quickstart

Run the docs website and API locally on port 333.

Dry-run local server

$env:BOT_DRY_RUN="true"
$env:BOT_API_KEY="local-test-key"
$env:TELEGRAM_WEBHOOK_SECRET="local-webhook-secret"
$env:TELEGRAM_BOT_TOKEN="local:dry-run"
npm run dev:333

Real-time polling

$env:BOT_DRY_RUN="false"
$env:TELEGRAM_BOT_TOKEN="123456:your_real_token"
npm run dev:333:poll
02

Endpoints

The same routes run locally and on Vercel.

GET

/api/health

Reports whether required environment variables are configured.

POST

/api/telegram

Calls Telegram methods while keeping the bot token server-side.

POST

/api/webhook

Receives Telegram updates and handles /start and /ping.

POST

/api/set-webhook

Registers the deployed webhook URL with Telegram.

03

Rate limits

Telegram flood limits are respected instead of bypassed.

Private chat 1 msg/sec
Group chat 20 msg/min
Broadcast 30 msg/sec

05

Vercel deploy

Push to GitHub, import the repo in Vercel, then set the secrets.

Required environment variables

TELEGRAM_BOT_TOKEN=123456:your_botfather_token
BOT_API_KEY=make_this_a_long_random_secret
TELEGRAM_WEBHOOK_SECRET=another_long_random_secret
06

Webhook setup

After deployment, register the production webhook URL.

Register webhook

curl -X POST "https://your-project.vercel.app/api/set-webhook" \
  -H "content-type: application/json" \
  -H "x-api-key: YOUR_BOT_API_KEY" \
  -d "{}"
